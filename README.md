# HR Employee Attrition Analysis

## 📌 Project Overview

This project analyzes employee data to understand employee attrition patterns and identify the factors associated with employee turnover.

The analysis was performed using Python and focused on data cleaning, exploratory data analysis, visualization, and identifying patterns across different employee characteristics.

## 🎯 Objectives

- Analyze overall employee attrition patterns
- Compare attrition across different job roles and departments
- Analyze attrition based on employee age and experience
- Identify important patterns in employee data
- Create visualizations to communicate analytical findings

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Project Files

- `HR-Employee-Attrition.ipynb` — Jupyter Notebook containing the complete analysis
- `HR Employees Attrition.pptx` — Project presentation containing analysis and visualizations

## 🔍 Analysis Performed

The project includes analysis of employee attrition across factors such as:

- Job Role
- Department
- Age
- Experience
- Employee-related characteristics

Data was cleaned and prepared using Pandas and NumPy before performing the analysis and creating visualizations.

## 📊 Visualizations

Matplotlib and Seaborn were used to create charts for understanding employee attrition patterns and presenting the analysis in an easy-to-understand format.

## 💡 Key Insights

The analysis helps identify patterns in employee attrition across different employee groups and provides a better understanding of the factors associated with employee turnover.
